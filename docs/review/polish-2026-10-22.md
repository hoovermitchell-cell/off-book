# Polish pass, 2026-10-22 (branch `polish/drill-screen`)

Findings from Codex's independent review (`codex-review-2026-10-22.md`) and Claude's own pass,
with what happened to each. Severity: P1 a normal user hits it, P2 real downside, P3 minor.

| # | Sev | Finding | Status |
|---|---|---|---|
| C1 | P2 | Stockfish failing to load left the screen on "Loading…" forever | Fixed: load errors and a 60 s timeout reject; a crash mid-game rejects the pending search |
| C2 | P2 | Maia or Stockfish failing mid-game locked the board with no message | Fixed: the round ends with "The engine stopped" and New game; test added |
| C3 | P2 | A typed underpromotion (a8=N) played a queen | Fixed: the parsed promotion is passed through |
| C4 | P2 | Resigning while a wrong prep move was judged left that move on the board, then removed it silently | Fixed: resign takes it back before game over renders; test added |
| C5 | P2 | Two open tabs overwrote each other's tallies and learned moves | Fixed: every save applies to the latest stored progress; other tabs' changes show live; test added |
| C6 | P2 | Blocked storage (private window) silently lost progress | Fixed: a notice says progress won't survive closing the browser; test added |
| C7 | P2 | Keyboard users lost focus after each typed move | Fixed: focus returns to the move box on your turn, and after New game |
| C8 | P2 | Prep moves on the scoresheet were marked by color alone | Fixed: hidden "(prep)" text for screen readers, and the prep-ends icon marks where prep ended |
| C9 | P2 | "A drop of 1.0 is about a 50% swing" was wrong for score differences | Fixed: the panel explains the score and the drop without a probability claim |
| C10 | P2 | "Looked N moves ahead" overstated Stockfish's depth | Fixed: "searched to depth N (counted in single moves, and deeper on forcing lines)" |
| C11 | P3 | Changing the rating mid-search mislabelled Black's reply | Fixed: the rating is captured before the search; test added |
| M1 | P2 | No favicon (404 on every load) | Fixed: Off the page favicon, PNG fallback, apple-touch icon, description |
| M2 | P2 | About 15 MB loads with only "Loading the engines…" | Fixed: shows Black's engine download percentage |
| M3 | P3 | Fonts ship as TTF (Kalam 427 KB) | Deferred: needs fontTools for WOFF2 subsetting; in backlog |
