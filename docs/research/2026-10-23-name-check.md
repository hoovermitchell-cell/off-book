# Name check: "Off Book"

Date: 2026-10-23. Scope: is "Off Book" safe to use publicly for this chess opening trainer (decision 10)?

**Not legal advice.** This is a desk check by web search and page fetches, not a clearance search. The USPTO search tool was not queried directly (only the TSDR status page for one known record was reachable), so a mark filed under a different spelling or in a different register may be missing. A trademark attorney or a full commercial search would be the proper step before a paid or store-listed launch.

## Risk read

The exact mark OFF BOOK is registered, live and maintained, in Class 9 for mobile app software, with an active commercial owner and several other actor apps using the same name in both stores. The goods differ (acting scripts vs chess openings), and the phrase is a genuine chess term, which cuts in Mitch's favour on likelihood of confusion. It does not remove the exposure, because "learning lines / memorizing" software in Class 9 is close enough that a registrant could object, particularly on an app store where search results will mix the two.

- **(a) Showing it in a talk: negligible.** Non-commercial, no filing, no listing. No action needed.
- **(b) Public GitHub repo `off-book`: low.** The slug is free, the project is free and open-source, and a name collision on a repo is routine (six `off-book` repos exist already). Expect no trouble, but a hosted site on a domain like offbook-something.app would draw closer attention than the repo. Cheap hedge: keep "Off Book" as a working title and describe it in the README as a chess opening trainer so it reads as the chess term, not as a brand.
- **(c) Future app-store listing: meaningful.** Same Class 9, same name as a live registration, and the stores already list multiple actor apps called Off Book. A takedown complaint or a rejected listing is plausible, and a school-linked free app would not make that cheaper to resolve. Do a proper search, or choose a different store name, before submitting.
